# 在线刷题网站（纯静态）

一个纯前端刷题网站，双击 `index.html` 即可在浏览器打开使用。**无需服务器、后端、数据库，也无需联网。**

技术栈：HTML + CSS + 原生 JavaScript + 浏览器 localStorage。题库用 Node.js 脚本从 Markdown 转换成 JavaScript 数据文件。

## 一、如何运行

直接双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开即可。

> 提示：如果双击后浏览器提示无法访问，也可以在浏览器地址栏手动输入该文件的路径打开，或右键 `index.html` → 选择「打开方式」→ 选择浏览器。

## 三、功能

- **首页**：显示每个题库的名称、题量、已做进度（已做 / 总数、答对数量、正确率）。
- **答题页**：显示当前第几题 / 共几题、已答对几道；展示题干与全部选项；选中选项有明显高亮；点「提交」后立即显示对错，答错时显示正确答案和解析；支持上一题 / 下一题；做到最后一题可「交卷」。
- **结果页**：显示答对、答错、正确率、未答数量，以及错题列表（题号、题干、你的答案、正确答案、解析）。
- **进度持久化**：答题进度、已答题目、答对数量、错题列表均存入 localStorage，刷新或关闭浏览器后重新打开，数据仍在。
- **防重复提交**：每道题提交一次后即锁定，重复点击「提交」不改变成绩、不重复计错、不重复累加答对数量。
- **脏数据跳过**：转换时校验每道题，有问题的题标记为异常并在答题时自动跳过，结果页提示跳过了几道异常题。

### 整卷作答与练习轮次（最新新增）

- **选项保留**：选完选项可以不提交，直接翻题，选项自动保存；翻回来、刷新页面、关掉再开，选项都还在。喜欢即时反馈的仍可点「提交」，两种方式可混用。
- **统一交卷**：交卷时把「已选未提交」的题统一判分（计入成绩和错题本），完全没选的题记为「未答」；交卷确认弹窗会分开提示「已提交 X 题 / 已选未提交 Y 题（交卷自动判分）/ Z 题没做」。交卷后自动清空本轮进度，下次从首页进入即为全新一轮（历史轮次仍可在「练习记录」回看）。
- **练习轮次**：每次交卷记为一轮，完整保存本轮每道题的作答快照（题干、选项、答案、解析、你的选择、对错），最多保留 50 轮。
- **回看每轮**：首页「练习记录 (n)」进入，按题库分组、时间倒序列出每一轮（时间、正确率、答对/答错/未答、用时）；点任意一轮展开全部题目详情，正确答案标绿、错选标红。
- **刷该轮错题**：轮次详情里有「刷本轮的错题 (n)」按钮，只重做该轮答错的题；重做答对会自动移出错题本。

### 刷题模式与答题辅助（第一批新增）

- **设备自适应**：自动判断手机端（窄屏）与电脑端（宽屏），电脑端加宽内容区，移动端优先布局。
- **答题卡**：点「答题卡」一屏查看所有题号，答对绿色、答错红色、当前题蓝框、未做灰色；点任意题号直接跳转。
- **交卷确认**：交卷前弹窗提示「还有 X 题没做」，确认后才交卷。
- **剩余题数**：答题页顶部实时显示「剩余 X 题」。
- **多种刷题模式**（首页入口）：
  - 「继续刷题 / 开始刷题」：继续上次答题位置；
  - 「刷错题」：只刷错题本里的题；
  - 「刷收藏」：只刷收藏的题（收藏功能在后续批次开放标记入口，数据层已就绪）；
  - 「按章节刷」：按章节选题（Web 题库 6 个章节，Java 题库 1 个章节）；
  - 「随机刷题」：随机打乱题目顺序。
- **随机选项顺序**：答题页顶部开关，打开后每题选项随机排列（每题顺序在会话内保持一致，不影响判题）。
- **答题计时**：顶部实时显示本次答题总用时（MM:SS）。
- **单题计时**：每题显示本题用时，提交后记录到进度中。
- **快速跳到第一道错题**：答题卡内一键跳转。
- **清空进度**：首页一键清空答题进度和错题记录（收藏保留）。
- **章节修复**：修复了章节标题被误拼进上一题解析的隐藏问题，每道题现在带有章节字段。

### 错题本（第二批新增）

- **错题本独立页面**：首页右上角「错题本」进入，所有题库的错题集中管理。
- **按题库分组**：错题按所属题库分组显示，每道题显示题号、题型、章节、重做次数、题干、你的答案、正确答案、解析。
- **答对自动移出**：在「刷错题」模式中答对一道错题，自动从错题本移除。
- **手动移出**：错题本里每道题有「移出」按钮（带确认）。
- **重做次数记录**：错题模式下重做仍答错，次数 +1；首页「刷错题」每次进入都是重做模式（自动解除锁定）。
- **导出文本**：一键导出为 `错题本.txt`（含筛选结果，保留代码块内容）。
- **搜索**：按题干关键词实时搜索。
- **章节筛选**：下拉选择章节，只看该章节的错题。

### 收藏与标记（第三批新增）

- **收藏 / 星标**：答题页题干上方有「☆ 收藏」按钮，点击变成「★ 已收藏」，再次点击取消。
- **题目标记**：答题页「标记」按钮循环切换 无 → 已掌握 → 有疑问，标记状态在答题页和收藏页同步。
- **收藏列表页面**：首页右上角「收藏」进入，收藏题按题库分组，显示题干、答案、解析。
- **题目备注**：收藏页里每道题有备注输入框，失焦自动保存。
- **收藏导出**：一键导出为 `收藏.txt`。

### 进度与统计（第四批新增）

- **统计页面**：首页右上角「统计」进入，按题库展示学习数据。
- **总览**：正确率、已做/总数、错题率、总刷题时长。
- **按章节进度**：每个章节的完成进度条。
- **按题型正确率**：单选题 / 多选题 / 判断题分别统计。
- **成绩趋势图**：历次交卷正确率的折线图（SVG 绘制，无第三方库）。
- **每日刷题数量**：按天聚合的刷题量与正确率。
- **答题历史**：每次交卷自动记录（题库、模式、答对/答错/正确率/用时），供统计使用。

### 界面与体验（第五批新增）

- **设置面板**：首页右上角「设置」进入，所有设置实时生效并记忆（存 localStorage）。
- **深色模式**：浅色 / 深色一键切换，全套配色适配。
- **字体大小**：中 / 大 / 特大三档，作用于题干和选项等阅读区域。
- **大按钮模式**：开启后所有按钮更高，更适合触屏。
- **答题音效**：答对高音、答错低音（浏览器 Web Audio 实时生成，无音频文件），可关闭。
- **移动端底部固定操作栏**：手机端答题页的提交/翻题按钮固定在屏幕底部，不随滚动消失。
- **顶部固定进度条**：答题页的进度信息固定在顶部。
- **键盘快捷键**：电脑端按 A/B/C/D/E 直接选中选项，回车提交。
- **左右滑动切题**：手机端在答题区域左右滑动切换上一题/下一题。
- **轻动画**：答对/答错反馈淡入、选项轻微脉冲，页面切换淡入（均为轻微效果，不喧宾夺主）。
- **加载失败提示**：题库数据文件缺失时有明确提示。

### 题库与内容（第六批新增）

- **题库信息页**：首页点题库名进入，查看题型分布、章节分布、异常题列表。
- **异常题清单页**：汇总显示所有题库的异常题及原因（也可在信息页按题库查看）。
- **题型筛选**：题库卡片「按题型刷」，只刷单选题 / 多选题 / 判断题。
- **题目搜索**：首页搜索框按题干关键词跨题库搜索题目，点击结果直达对应题目。
- **题库范围筛选**：首页下拉框选择题库后不跳转，搜索和浏览题目都限定在该题库内。
- **题库导入**：首页「导入」，粘贴 Markdown 题库即可在前端解析，导入的题库存入浏览器（可删除），异常题同样自动标记跳过。
- **题库版本号**：data.js 生成时自动带版本时间，首页底部显示。
- **关键词高亮**：错题本搜索时，题干和解析里的匹配词高亮显示。

## 四、数据存储

所有数据只存在浏览器 localStorage 中，键名约定：

| 键 | 含义 |
| --- | --- |
| `progress_java` | Java 题库的答题进度（当前题、已答题目、答对数量、题目顺序） |
| `wrong_java` | Java 题库的错题记录（题号 → 重做次数、首次答错时间） |
| `fav_java` | Java 题库的收藏题号列表 |
| `marks_java` | Java 题库的题目标记（备注、已掌握/有疑问） |
| `history_java` | Java 题库的答题历史记录（每次交卷一条，供统计） |
| `rounds_java` | Java 题库的练习轮次记录（每轮含全部题目作答快照，可回看/刷该轮错题） |
| `result_java` | Java 题库最近一次交卷的结果快照 |
| `progress_web` / `wrong_web` / `fav_web` / `marks_web` / `history_web` / `rounds_web` / `result_web` | Web 题库同理 |

## 五、如何更新题库

修改 `题库/*.md` 后，在项目根目录运行：

```bash
node tools/convert.js
```

即可重新生成 `js/data.js`。

## 六、题库格式约定

每道题以 `### 题号. 题型` 开头，题型为「单选题 / 多选题 / 判断题」：

```markdown
### 1. 单选题

题干内容（可含代码块）

- A. 选项A
- B. 选项B
- C. 选项C
- D. 选项D

**答案**：B
**解析**：解析内容
```

- 单选题、多选题选项写成 A、B、C、D；判断题选项为「A 正确、B 错误」（原文没写选项时转换会自动补上）。
- 答案可以是单个字母，也可以多个字母（用顿号、逗号或空格分隔）。
- 题干里的代码块会原样保留。

转换时会对每道题做脏数据检查：

1. 是否有选项；
2. 是否有答案；
3. 答案字母是否都在选项范围内；
4. 多选题答案是否至少两个；
5. 判断题答案是否只有 A 或 B；
6. 答案与解析是否明显矛盾（解析明确指向某个字母，但答案里没有）。

有问题的题会标记为异常并记录原因，答题时跳过；结果页会显示跳过了几道异常题。

## 八、关于「答案与解析不照应」的处理

转换时会额外做一轮一致性核对：若某题的解析里明确写出结论（如「故选 D」「正确答案是 D」「答案是 D」等），但答案字段里没有该字母，则判定为「答案与解析不照应」。按约定**以答案为准、解析原样保留、标记为异常并跳过**，不修改任何题目内容。

例如 Java 第 108、174 题：答案均为 A，但原解析误以为会抛 ConcurrentModificationException、得出「选 D」的结论，两者矛盾，因此被标记为异常跳过。

## 九、UI 说明

- 极简三页统一风格，移动端优先，按钮大、字号大，适合单手操作。
- 选中选项高亮，答对绿色、答错红色，配色统一、圆角、留白。
- 无动画、无渐变、无音效、无深色模式、无多主题，不引入任何 UI 框架与在线字体。
