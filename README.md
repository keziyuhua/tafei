# 在线刷题网站（纯静态）

一个纯前端刷题网站，双击 index.html 即可在电脑浏览器打开使用。无需服务器、后端、数据库，也无需联网。

技术栈：HTML + CSS + 原生 JavaScript + 浏览器 localStorage。题库用 Node.js 脚本从 Markdown 转换成 JavaScript 数据文件。


一、设计思路

首先我是一个小白，所以我的思路是先用ai做出一个mvp，仅有最基础功能，后续我用我平时爱用的6A工作流（6A工作流：先对齐需求，再设计，再拆任务，再确认，再执行，再评估。我是小白，少术语，多反问。）精简一下大概就是这样，用网页ai辅助我共同探讨完成了应该有的功能以及进一步目标。由于事先已经有了完整的大纲，后续我就完全按照大纲来，一步步推进，整体的设计思路就是这样。
二、AI 使用情况
可以说所有的东西都是ai做的，我只负责提供具体方向，尽可能精确告诉ai我想到的东西长什么样子，然后ai帮我去完成。
在具体需求与明确指令下，可以说ai基本没有给过我什么错误方案，只是有点地方审美不足，理解不是很到位，难免会有一些小瑕疵，我要求ai每个模块跑完之后必须先给我验收，并进行了git化管理，每个模块跑完之后我看看新更新的地方有没有什么bug就行了，有的话修一下就可以

三、运行方式

电脑，双击即可。项目是纯静态，不需要构建，不需要安装依赖。
手机，上传到我的GitHub仓库。
依赖说明：运行网站只需要一个静态文件服务器，或者直接双击 index.html。不需要 Node.js，不需要数据库。更新题库需要 Node.js 运行 tools/convert.js，这是开发阶段用的，不影响网站运行。

附：题库更新与异常题说明

题库格式约定。每道题以三个井号加题号加题型开头，题型为单选题、多选题、判断题。题干内容可以含代码块。选项写成横杠 A 点 选项A，依次 B、C、D。答案写成两个星号答案两个星号，冒号，字母。解析写成两个星号解析两个星号，冒号，解析内容。

单选题、多选题选项写成 A、B、C、D；判断题选项为 A 正确、B 错误，原文没写选项时转换会自动补上。答案可以是单个字母，也可以多个字母，用顿号、逗号或空格分隔。题干里的代码块会原样保留。
